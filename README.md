# Odin Recipes

This project is part of **The Odin Project** Foundations curriculum. It is a basic recipe website built using HTML and structured using Git version control.

## 🍽️ Included Recipes

- **Lasagna** - A classic layered Italian baked dish with spiced veggie-tomato sauce and creamy white sauce.
- **Pancakes** - Light and fluffy homemade breakfast pancakes.
- **Brownies** - Rich, fudgy chocolate brownies.

## 🛠️ Concepts Learned & Applied

- HTML boilerplate structure (`<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`)
- Text formatting using `<h1>` to `<h3>` headings and `<p>` paragraphs
- Working with images (`<img>`) and aspect ratio controls
- Constructing unordered (`<ul>`) and ordered (`<ol>`) nested lists
- Linking local pages using relative file paths (`../`)
- Version control using Git and GitHub (`add`, `commit`, `push`)
